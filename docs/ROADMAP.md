# BetterTTY roadmap

## 1.0 — Andromeda

Foundation release:

- saved SSH sessions and groups
- password/private-key authentication
- known-host verification
- xterm.js terminal
- SFTP two-panel file manager
- transfer queue and safety workflows
- config management and diagnostics
- Linux, Windows, and macOS packaging foundations

## 1.0.x — Andromeda maintenance

Near-term polish after the first release:

- release bug fixes
- packaging and installer polish
- Microsoft Store preparation
- documentation and website integration
- accessibility and UI consistency fixes

## 1.1+

Candidates for future releases:

- encrypted/master-password secret storage
- richer file operations such as rename
- transfer resume
- parallel transfer options
- sync/mirror workflows
- log viewer
- improved update/distribution channels
- additional platform packaging automation

Roadmap items are directional, not promises or fixed release dates.
